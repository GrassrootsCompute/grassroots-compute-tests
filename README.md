Grassroots Compute publishes the tasks, hidden tests, graders and raw results behind each episode so anyone can re-run them. Episode 1: local 125B MoE vs Claude Sonnet 4.6 on five coding rounds. Episode 2: DeepSeek-V4-Pro distilled 9B vs the original Qwen3.5-9B, a local 125B model and the teacher, on 36 fresh questions. Episode 3: the cloud-vs-local bills from episodes 1–2 plus an hourly AI paper-trading experiment, with a script that recomputes every number in the video.
